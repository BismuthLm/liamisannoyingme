# liamisannoying.me

A personal website featuring generative art, poetry, games, and tools.

## Structure

- **src/** - Main source directory
  - **Pages/** - HTML pages
    - `index.html` - Homepage
    - `art.html` - Interactive geometric art canvas
    - `poem.html` - Poetry generator
    - `GamesPage.html` - Games listing
    - `ToolsPage.html` - Tools listing  
    - `AboutPage.html` - About page
  - **Styles/** - CSS stylesheets
    - `universial.css` - Global styles and CSS variables
    - `navigation.css` - Navigation component styles
    - `index.css` - Homepage-specific styles
  - **Scripts/** - JavaScript files
    - `poem.js` - Poetry generator logic
  - **Imgs/** - Images and assets

## Features

- **Responsive Design** - Works on desktop and mobile devices
- **Modern CSS** - Uses CSS custom properties and modern layout
- **Interactive Art** - Canvas-based geometric animations
- **Poetry Generator** - Dynamic text generation with linguistic rules
- **Consistent Navigation** - Unified navigation across all pages

## Tech Stack

- HTML5
- CSS3 with custom properties
- Vanilla JavaScript
- Canvas API for art generation
